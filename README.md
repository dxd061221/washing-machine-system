# 宿舍洗衣机状态参考系统

让宿舍学生随时随地查看洗衣房每台洗衣机的实时状态，避免白跑一趟。**零依赖、纯 Node.js 实现，双击即可运行。**

## 快速开始

方式一（双击）：运行 `启动.bat`
方式二（命令行）：

```
node server.js
```

然后打开：
- 学生端：http://localhost:3000/
- 管理端：http://localhost:3000/admin

首次启动会自动生成演示数据（12 号宿舍楼 6 台洗衣机），可在管理端增删改。

## 功能

| 模块 | 说明 |
|---|---|
| 状态展示 | 卡片式展示每台洗衣机：编号、位置、状态、更新时间；顶部汇总空闲/使用中/待取衣/故障数量 |
| 状态机 | 空闲 → 使用中 → 待取衣 → 空闲；任意状态可报修进入故障；维修完成恢复空闲；每次迁移记录日志 |
| 一键标记 | 学生点击「开始使用 / 洗完了 / 已取走 / 报修」即可更新状态 |
| 防滥用 | 每个 IP 30 秒内只允许一次状态操作 |
| 防过期 | 状态超过 2 小时未更新，自动标记「可能已过期」 |
| 管理端 | 机器增删改查、状态日志（最近 100 条）、报修处理（结单后机器自动恢复空闲） |
| 自动刷新 | 学生端每 10 秒、管理端每 15 秒自动拉取最新数据 |

## API 一览

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | /api/machines | 机器列表 + 状态汇总 + 过期标记 |
| POST | /api/machines/:id/status | 更新状态（body: `{to, by}`） |
| GET | /api/logs | 状态日志 |
| GET | /api/faults | 报修记录 |
| POST | /api/admin/machines | 新增机器（body: `{name, location}`） |
| PUT | /api/admin/machines/:id | 修改机器（body: `{name?, location?}`） |
| DELETE | /api/admin/machines/:id | 删除机器 |
| POST | /api/admin/faults/:id/close | 报修结单（机器自动恢复空闲） |

## 数据存储

数据保存在 `data/store.json`，修改后每 3 秒自动落盘；删除该文件可重置为演示数据。

## 状态颜色约定

空闲 = 绿色 · 使用中 = 蓝色 · 待取衣 = 橙色 · 故障 = 红色（颜色 + 文字双重表达）

## 备注

演示数据为系统内置示例，可按需在管理端修改；本系统面向宿舍内部使用，管理端未加密，如需上线请自行加登录鉴权。
